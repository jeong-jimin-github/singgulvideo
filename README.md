# Singgul Video

간단한 영상(또는 미디어) 관련 기능을 제공하는 React 기반 웹 프로젝트입니다.

## 🔗 Live Demo

배포 링크: https://singgulvideo-three.vercel.app/

## 🚀 Tech Stack

- JavaScript
- React (Create React App 기반)
- CSS
- HTML

## 📦 설치 및 실행

```bash
# 1) 패키지 설치
npm install

# 2) 개발 서버 실행
npm start
```

실행 후 브라우저에서 `http://localhost:3000` 접속

## 🛠️ 사용 가능한 스크립트

```bash
npm start      # 개발 서버 실행
npm test       # 테스트 실행
npm run build  # 프로덕션 빌드
npm run eject  # CRA 설정 분리(되돌릴 수 없음)
```
